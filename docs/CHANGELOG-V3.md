# NextMind Desktop 3.0.0

## Added

- Future Workspace visual system with unified custom window chrome.
- Profiles for focused, planning and personal workspace layouts.
- Local command search across NextMind actions, zones, widgets and Start-menu apps.
- Clock & Date and Quick Note widgets with per-profile state.
- Immediate appearance preview with explicit Apply, Reset and close-to-rollback semantics.
- Setup ZIP with verified backup and rollback support.
- Self-contained Portable ZIP with a separate data root and no autostart registration.

## Changed

- Readable dark accent selector, scrollbars and resize surfaces.
- Responsive Clock & Date widget across window sizes and DPI scales.
- Zones, profiles, widgets and appearance migrate to configuration schema V5.
- Production UI no longer contains V3 preview-session labels.

## Preserved

- Local-only operation with no account, cloud service or telemetry.
- Existing configuration, zone content, layout geometry, notes and autostart preference during an in-place update.
- Opt-in, journalled Managed Desktop Moves and the no-delete/no-overwrite safety model.
