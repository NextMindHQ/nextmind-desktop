# Screenshot and demo plan

Rule: **never publish a screenshot of a real desktop.** Use a dedicated demo environment.

## Demo environment
* Use a throw-away Windows user or VM with a neutral wallpaper and no personal data.
* Point `NEXTMIND_DESKTOP_CONFIG_DIR` at a temp folder so the demo has its own config and log.
* Fill the Desktop and zones with fake sample files and shortcuts (e.g. `Project Notes.txt`, `Budget.xlsx` placeholders, shortcuts to Notepad/Calculator).
* Check every image for usernames, paths, window titles, notifications and the taskbar before publishing.
